# hightech — le plan d'ingénieur

Le thème par défaut de Zoé. Un jeu de **tokens** (pas de formes) : les composants les
lisent via `var(--z-*)`.

**Identité :** papier greige, **IBM Plex Mono**, **angles vifs** (`--z-radius: 0`), zéro
ombre portée, bleu `#006eff` **en filet** (focus, actif, onde).

Un hightech arrondi n'est plus un hightech — le radius 0 est l'ADN, pas un détail.

**Charger :** `<link rel="stylesheet" href="skins/hightech/hightech.css">`. Le swap se
teste avec le sélecteur de peau (`examples/skin-switch.js`).
