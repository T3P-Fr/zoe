z-code

Du code tel qu'écrit : un bloc comme un <pre>, ou une puce au fil du texte avec inline. Rien d'injecté, rien d'échappé, rien de coloré. Changez la peau en haut à droite — tout suit.

1 · Le bloc — <z-code>

npm run dev # http://localhost:5173 <z-button tone="soft">Annuler</z-button> <z-button type="submit">Envoyer</z-button>

Chaque espace et chaque retour compte (white-space: pre) : écrivez le contenu au ras de la balise. Du HTML dans le code s'écrit &lt; — Zoé n'échappe rien à votre place.

2 · En ligne — inline

Installez avec npm install, puis lancez npm run dev : la page est servie sur localhost:5173.

<p>Installez avec <z-code inline>npm install</z-code>, puis lancez <z-code inline>npm run dev</z-code>.</p>

Une puce calée sur la ligne de base, au padding serré : elle ne casse pas l'interligne. inline est un attribut de forme, pas un état — le CSS le lit par z-code[inline].

3 · Une longue ligne défile, elle ne casse pas la boîte

"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --disable-gpu --hide-scrollbars --window-size=1200,1800 --screenshot=demo.png http://localhost:5173/

Dans une boîte de 24 rem, la ligne défile à l'horizontale (overflow-x: auto) : le code reste intact, la mise en page aussi.

4 · La même chose, en calques

npm run dev # http://localhost:5173

Le fond devient une pièce ; le code passe au-dessus. Les calques s'écrivent sur une ligne : en white-space: pre, un retour entre deux <z-layer> serait une ligne vide dans le rendu.

5 · Repeint — quatre tokens

const zoe = await import("/zoe.js"); zoe.tune("volume", .8); 
.sombre {
  --z-code--background__color: #1d1a17;
  --z-code--infos__color: #f3ece0;
  --z-code--background__border: transparent;
  --z-code--background__radius: 0;
}

La surface, le filet, les coins, l'encre : toute la grammaire du composant. Sans ces tokens, il boit la peau (--z-surface-sunken, --z-line, --z-radius, --z-ink).
