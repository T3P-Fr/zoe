z-badge

Une pastille de statut ou de compteur. Elle n'ajoute presque rien : le ton et la taille viennent du socle, la peau fait le reste. Changez la peau en haut à droite — tout suit.

1 · Le ton — tone

Nouveau main complement soft payé 3

Sans ton, la pastille est discrète : surface et filet de la peau. Avec, elle boit les trois swatches du variant. Un chiffre seul reste un rond, un mot une gélule — et le rayon est celui de la peau (HighTech garde ses angles).

2 · La même chose, en calques

3 3 
.notif > z-layer[part="background"] { animation: pulse 1.4s ease-in-out infinite; }

Deux rôles, pas plus : le fond et ce qui informe. Le second pulse — c'est le fond qui respire, le chiffre ne bouge pas. Impossible quand fond et texte sont le même élément.

3 · La taille — size

xs s défaut l xl

Un badge fait .75em de son contexte, et size ajoute son cran. Tout l'intérieur est en em : padding, filet, rayon suivent.

4 · Dans un bouton — les facteurs se composent

Messages 3 Messages 3 Brouillons 12 
<z-button>Messages <z-badge tone="danger">3</z-badge></z-button>
<z-button size="l">Messages <z-badge tone="danger">3</z-badge></z-button>
<z-button tone="soft">Brouillons <z-badge>12</z-badge></z-button>

Le badge grandit avec le bouton size="l" sans qu'on lui dise rien : em s'hérite, donc les facteurs se multiplient. C'est voulu — un badge dans un gros bouton doit être gros aussi.

5 · Le nombre change, la pastille repope

+1 message 0 aucun message 
compteur.textContent = ++total;
compteur.play("enter");   // rejoue l'entrée : le chiffre repope, là où est l'œil

Cliquez : le chiffre monte et la pastille repope — une ligne, l'état enter rejoué. Le role="status" est sur la rangée, pas sur le badge : c'est le contexte qui s'annonce.
