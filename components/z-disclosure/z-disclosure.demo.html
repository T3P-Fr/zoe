z-disclosure

Un titre qui agit comme un bouton, un panneau qui se révèle en glissant. Vous écrivez les deux pièces, Zoé pose la sémantique (aria-expanded, inert). Changez la peau en haut à droite — tout suit.

1 · Deux pièces — label et panel

Ce que Zoé garde natif Titres, paragraphes, liens — lus par les moteurs de recherche. Le dépli ne fait que les cacher ou les montrer. Déjà ouvert — open L'attribut est la source de vérité : :state(open) le reflète, .open le lit et l'écrit. Désactivé Ce panneau ne s'ouvrira pas : disabled coupe le geste.

Cliquez le titre, ou Tab puis Entrée / Espace. La hauteur glisse (une grille 0fr → 1fr) : aucun max-height à deviner, quelle que soit la longueur du contenu.

3 · Repeint par le pacte

Le chevron devient une croix, le titre prend l'accent Aucun token propre au dépli : on vise ses pièces depuis l'hôte — z-disclosure:state(open) > [part=label]. Le > protège un dépli imbriqué du CSS de son parent. 
.accent:state(open) > [part=label] { color: var(--z-accent); }
.accent:state(open) > [part=label]::before { rotate: 135deg; }

Deux lignes de CSS, zéro JS : l'état open est un sélecteur natif, les pièces ont un nom.

4 · Piloté en JS — une FAQ

Tout ouvrir rien n'a bougé
Puis-je changer de peau sans toucher au HTML ? Oui : une peau est un fichier de tokens. Le dépli ne bouge pas d'une ligne. Un dépli peut-il en contenir un autre ? Oui — chaque dépli cherche ses pièces en enfants directs. La preuve Un dépli dans un dépli : le parent ne repeint pas l'enfant. Comment n'en garder qu'un seul ouvert ? Avec z-accordion, qui coordonne. Seul, un dépli ne connaît pas ses voisins. 
const plis = [...faq.querySelectorAll(":scope > z-disclosure")];
tout.addEventListener("click", () => {
  const ouvrir = plis.some((pli) => !pli.open);
  plis.forEach((pli) => { pli.open = ouvrir; });   // par API : pas d'événement `toggle`
});
faq.addEventListener("toggle", (e) => dit.textContent = `${e.target.open ? "ouvert" : "fermé"} : ${e.target.querySelector("[part=label]").textContent}`);

Le bouton pose .open : pas d'événement, c'est le programme qui parle. Un clic sur un titre, lui, émet toggle — la phrase à droite du bouton le dit.
