z-progress

Une barre de progression (role="progressbar") : value / max devient un pourcentage que le CSS dessine — et un mode « inconnu » qui balaye. Changez la peau en haut à droite — tout suit.

1 · Forme courte

value sur max (100 par défaut). Le JS pose --z-progress__value ; le CSS en fait une largeur, il ne calcule rien.

2 · Inconnu — indeterminate

Quand on ne sait pas combien : un segment balaye la piste, aria-valuenow est retiré (on ne prétend pas connaître une valeur qu'on n'a pas). État durable : attribut, :state(indeterminate) et .indeterminate disent la même chose.

3 · Tons et tailles

tone colore le remplissage via --z-tone__fill ; size règle le texte, la hauteur de la piste (.5em) suit.

4 · En calques — background + marker

.epaisse { --z-progress--track__height: 1em; --z-progress--fill__color: var(--z-ink); }
.vivante > [part=marker] { animation: pulse 1.2s var(--z-ease) infinite; }

Même rendu que la forme courte. La seconde barre fait pulser son remplissage seul — la piste ne bouge pas : c'est ce que les calques permettent.

5 · Vivante — un curseur, puis un envoi simulé

Simuler un envoi au repos 
pilote.addEventListener("input", (e) => { barre.value = e.target.value; });

envoi.addEventListener("click", async () => {
  barre.indeterminate = true;            // on ne sait pas encore combien
  await attendre(900);
  barre.indeterminate = false;
  for (let pas = 0; pas <= 100; pas += 10) { barre.value = pas; await attendre(120); }
});

Le curseur pose .value, la largeur glisse. L'envoi commence inconnu (balayage) puis avance par paliers de 10 — sans sauter : la transition fait le reste.
