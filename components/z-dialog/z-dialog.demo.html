z-dialog

Une boîte modale bâtie sur le <dialog> natif : le navigateur donne le piège de focus, la page inerte et Échap ; Zoé ajoute les états, l'entrée et la sortie animées, les déclencheurs déclaratifs et le light-dismiss. Changez la peau en haut à droite — tout suit.

1 · La boîte canonique — commandfor + command

Supprimer…

Supprimer ce fichier ?

Cette action est définitive. Échap ou un clic sur le fond annulent.

Annuler Supprimer

Rien décidé pour l'instant. Aucune ligne de JS pour ouvrir ni fermer : le déclencheur vise l'id du z-dialog, jamais le <dialog> interne. Le bouton qui ferme donne sa value au returnValue.

2 · Les cinq placements — et l'API JS

center top bottom left right

Placée en center

Le centre surgit ; chaque bord glisse depuis son côté. Cliquez le fond pour fermer.

 
boite.placement = "top";     // ou l'attribut placement="top"
boite.show();                // dialog.showModal() + l'entrée
await boite.close("ok");     // joue la sortie, PUIS ferme — returnValue = "ok"

Une seule boîte, cinq déclencheurs : le programme choisit où elle se pose avant de l'ouvrir. open reste l'attribut source de vérité — show() ne fait que le poser.

Renommer le fichier

Rien renommé pour l'instant. Des boutons natifs cette fois : la soumission ferme la boîte après validation (videz le champ, puis Entrée), et la value du bouton soumetteur devient returnValue. Zoé n'intercepte que pour jouer la sortie d'abord.

4 · Refuser la fermeture — l'événement cancel

Écrire un mot…

Un mot

Fermer Envoyer 
brouillon.addEventListener("cancel", (evenement) => {
  if (mot.value.trim()) evenement.preventDefault();   // un brouillon non vide ne se perd pas
});

Échap, le clic sur le fond et command="request-close" passent tous par cancel (annulable) : un seul écouteur garde les trois portes. « Envoyer » (command="close") ferme sans demander.
