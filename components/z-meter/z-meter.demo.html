z-meter

Une jauge de mesure (role="meter") : une valeur dans une plage, colorée par ses seuils. Le JS publie un pourcentage, le CSS dessine. Changez la peau en haut à droite — tout suit.

1 · Forme courte

Sans seuil, la jauge reste neutre (accent). value est bornée à [min, max] ; max vaut 100 par défaut.

2 · Les seuils — low · high · optimum

Une batterie : sous low → :state(low), danger. Entre les deux : neutre. Dans la zone de optimum → :state(optimum), le ton (accent). Sans optimum, la zone haute est :state(high), succès.

3 · L'idéal prend le ton ; l'échelle inversée se repeint

.pollution:state(high) { --z-meter--fill__color: var(--z-danger); }

tone="success" peint l'idéal en vert. Pour un taux de pollution (« bas = bon »), optimum="0" rend la zone basse idéale ; la zone haute reste :state(high) — une ligne de CSS la repeint en danger.

4 · En calques — background + marker

.epaisse { --z-meter--track__height: 1.1em; --z-meter--fill__color: var(--z-ink); }

Même rendu que la forme courte : la piste est background, le remplissage marker. Les tokens --track / --fill les peignent dans les deux formes.

5 · Vivante — un curseur la pilote

pilote.addEventListener("input", (e) => {
  jauge.value = e.target.value;                           // l'attribut suit, le CSS redessine
  dit.textContent = jauge.states.find((s) => ["low", "high", "optimum"].includes(s)) ?? "neutre";
});
