z-segmented

Un choix unique parmi 2 à 5 options, en pilule. Vos <button part="segment">, et un indicateur qui glisse sous le choix — le mouvement dit quand ça a changé. Changez la peau en haut à droite — tout suit.

1 · Vos boutons, une pilule

Des <button> natifs : ils savent déjà recevoir le focus et le clic. value sur l'hôte présélectionne ; sans lui, rien n'est choisi et l'indicateur n'a rien à montrer. Au clavier : Tab une fois, puis ← → — naviguer, c'est choisir.

2 · Vivante — le choix change la page

periode.addEventListener("change", (e) => {
  dit.textContent = `Rapport par ${e.detail.value}`;   // e.detail.value ⟺ periode.value
});

Rapport par mois. change bulle avec { value } — seulement pour un geste qui change le choix.

3 · Désactivé — tout, ou un seul segment

disabled sur l'hôte : plus de clic, plus de clavier, tout s'éteint. Sur un seul <button disabled> : les flèches le sautent, le navigateur refuse déjà son clic.

4 · Repeint par le pacte

.pleine { --z-segmented--indicator__color: var(--z-accent); --z-segmented--segment__ink: var(--z-accent-ink); }
.sobre  { --z-segmented--background__color: transparent; --z-segmented--indicator__color: var(--z-accent-soft); --z-segmented--indicator__shadow: none; --z-segmented__gap: .25em; }

Le fond de la pilule, l'indicateur, son ombre, l'encre du courant, les marges : des tokens. Le glissé, lui, ne change pas — il vient de --z-dur-select et --z-ease-spring, donc de la peau.

5 · Tailles

Un seul réglage, la taille du texte : padding et rayon suivent en em, et l'indicateur est mesuré — il épouse le segment quelle que soit la taille.
