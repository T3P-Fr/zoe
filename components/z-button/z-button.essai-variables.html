z-button — une variable peut-elle appartenir au composant ?

Sans Shadow DOM. Survole les boutons : la tache de lumière suit ta souris, et c'est une variable CSS posée sur le bouton qui la déplace. Change la peau en haut à droite — tout suit.

1 · Trois boutons, trois valeurs — aucune capsule

Chacun a sa lumière, au bon endroit. Une variable CSS est posée sur un élément : elle est à lui, point. Il n'a jamais fallu de Shadow pour ça.

Aucun JS : ce sont des attributs lus par des sélecteurs CSS. Change la peau — HighTech resserre l'échelle, Claude l'étale.

2 · La fuite — et la ligne qui l'arrête

Les deux cartes posent leurs propres coordonnées (comme le ferait un composant parent). Survole la carte, pas le bouton, puis regarde le bouton.

Variable ordinaire
★ Il hérite

Sa lumière suit la souris même hors du bouton : la valeur de la carte est descendue jusqu'à lui.

@property { inherits: false }
★ Il ignore

Sa lumière reste au centre tant qu'on ne le survole pas lui. La valeur de la carte ne l'atteint pas.

Le seul vrai risque, c'est l'héritage vers le dedans. Il se coupe en une ligne — inherits: false —, pas avec une capsule. Le Shadow DOM, lui, laisse les variables CSS traverser sa frontière : il n'aurait rien réglé ici.
