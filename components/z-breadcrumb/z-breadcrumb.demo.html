z-breadcrumb

Vous écrivez les liens ; Zoé pose le sens (une navigation nommée) et le rythme (le « › » peint par le CSS). Survolez un maillon, parcourez-les au Tab. Changez la peau en haut à droite — tout suit.

1 · Le fil — <z-breadcrumb>

Accueil Boutique Chaussures

Des liens natifs — lus par les moteurs de recherche, suivis au clavier. Le séparateur n'est pas dans votre DOM : un lecteur d'écran ne le lit pas. Le dernier maillon est la destination : encre pleine, gras, plus cliquable.

2 · Le séparateur — --z-breadcrumb__separator

Documentation Composants z-breadcrumb Documentation Composants z-breadcrumb Documentation Composants z-breadcrumb 
.slash  { --z-breadcrumb__separator: "/"; --z-breadcrumb__gap: .8em; }
.point  { --z-breadcrumb__separator: "•"; --z-breadcrumb__gap: .6em; }
.fleche { --z-breadcrumb__separator: "→"; }

Une chaîne, entre guillemets. L'espace vit dans le séparateur (gap: 0 sur la rangée) : il reste centré entre deux maillons, quelle que soit la peau.

4 · Le sens, posé par Zoé

Au montage, le fil reçoit role="navigation" et un aria-label — « Fil d'Ariane » par défaut, ou votre label. Rien à recopier : ce que vous écrivez, c'est ce qui est montré ici.
