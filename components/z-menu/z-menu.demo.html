z-menu

Un menu d'actions (ARIA « menu button ») bâti sur z-popover : l'ancrage, le top layer et l'animation sont hérités ; z-menu ajoute les rôles, le clavier et l'activation. Vous écrivez les items ; Zoé les relie. Changez la peau en haut à droite — tout suit.

1 · Le menu d'actions — <z-menu>

Actions ▾

Aucune action choisie pour l'instant.

Ouvrez au clic, à Entrée, Espace ou ↓ (↑ entre par le dernier item). Dedans : ↓/↑ en boucle, Home/End, une lettre saute à l'item qui commence par elle (« s » → Supprimer), Entrée/Espace activent, Échap ferme et rend le focus au bouton. Chaque activation émet select — le composant émet, la page décide.

2 · Des liens — un <a href> est un item qui navigue

Aller à ▾
Haut de page Items désactivés Menu de bascules
Démo de z-popover

Le composant ne touche pas au clic d'un lien : il émet select, ferme, et le navigateur navigue comme d'habitude. Un lien dans un menu n'est plus un arrêt de tabulation (tabindex="-1") — c'est le menu qui en est un.

3 · Items désactivés — disabled, aria-disabled

Fichier ▾

Les deux formes sont sautées par les flèches et ignorées au clic. aria-disabled garde l'item lisible par un lecteur d'écran (il existe, il est juste indisponible) ; disabled le sort tout à fait.

4 · Rester ouvert — preventDefault() sur select

Affichage ▾ 
<!-- chaque item porte SON état, écrit par l'auteur (le code affiché ci-dessus
     retire role/aria-*, d'ordinaire posés par Zoé — ici c'est vous qui les écrivez) -->
<button part="item" role="menuitemcheckbox" aria-checked="true" value="grid">Grille</button>

affichage.addEventListener("select", (event) => {
  event.preventDefault();                       // le menu reste ouvert
  const item = event.detail.item;
  item.setAttribute("aria-checked", String(item.getAttribute("aria-checked") !== "true"));
});

Un menu de bascules : chaque item porte son état (role="menuitemcheckbox" + aria-checked — z-menu respecte un rôle déjà posé), et preventDefault() sur select garde le menu ouvert. La coche est trois lignes de CSS d'auteur.

5 · Hérité de z-popover — placement, align

Vers le haut, calé à droite ▾

Tout ce que sait z-popover, z-menu le sait : le côté, le bord d'alignement, le retournement quand ça déborde, le suivi du défilement, open et l'événement toggle. Sans value, c'est le texte de l'item qui part dans select.
