Soumettez vide : le groupe tremble et passe en error ; cochez une case, il s'apaise. Les cases partent sous le name du groupe : topics=design&topics=code. La case verrouillée ne suit pas la maîtresse.

const group = document.querySelector("z-checkbox-group");
group.value;                      // → ["code"]
group.value = ["design", "code"]; // coche exactement celles-là, en silence
group.count;                      // → 2
group.all;                        // → la maîtresse, ou null
group.addEventListener("change", () => group.value);
