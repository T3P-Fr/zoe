z-rating

Une note en étoiles. Le JS traduit le geste en un entier et publie deux nombres (--z-rating__value, --z-rating__stars) ; le CSS écrit les étoiles — aucun nœud injecté. Changez la peau en haut à droite — tout suit.

1 · Forme courte

Cliquez une étoile : elle devient la note. Au clavier, → ↑ ajoutent, ← ↓ retirent, Début / Fin vont aux bornes. readonly se lit sans se modifier ; disabled coupe tout.

2 · En calques — background · marker · contact

Même rendu que la forme courte : les étoiles vivent dans marker. La seconde rangée fait apparaître son fond au focus (Tab) — une pièce à part, impossible à viser en forme courte.

3 · Échelle, taille, couleur

.grande { --z-rating__size: 2.2em; --z-rating--full__color: var(--z-danger); }

max est le nombre d'étoiles — la chaîne publiée en compte autant. La taille et les deux couleurs (vides, pleines) sont des tokens.

4 · Vivante — la note s'écrit à côté

avis.addEventListener("input", () => { dit.textContent = `${avis.value} / ${avis.max}`; });
avis.addEventListener("change", () => { dit.textContent += " — geste terminé"; });

Aucune note. input suit chaque cran, change clôt le geste (clic posé, touche relevée).

5 · Elle part dans le formulaire

fieldset désactivé

Rien envoyé pour l'instant. La première note est required : à 0, le formulaire refuse.
