z-motion — les mouvements partagés

Chaque tuile est un @keyframes offert par Zoé. Cliquez pour le rejouer. Ils se branchent sur n'importe quel état, d'un composant Zoé ou de votre propre élément. Changez la peau en haut à droite — la courbe (--z-ease-spring) et la couleur suivent.

1 · Les presets, à voir bouger

La liste est lue dans la feuille elle-même : un preset ajouté à z-motion.css apparaît ici sans qu'on touche à cette page.

2 · Les brancher — sur un état, en une ligne

Cliquez : erreur 
z-button:state(error)            { animation: shake .35s var(--z-ease); }      /* chemin A : un composant Zoé */
z-element:state(release) > button { animation: pop .4s var(--z-ease-spring); } /* chemin B : votre élément */

Le mouvement est écrit en CSS, sur l'état. Le JS ne fait que poser l'état — ici, il pose error au clic pour la démonstration ; en vrai, c'est votre application qui le pose.
