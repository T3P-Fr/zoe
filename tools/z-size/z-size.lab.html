z-size — la taille réelle, et le débordement

Deux questions auxquelles le CSS ne répond pas seul : quelle taille fait vraiment cette boîte, et est-ce que ça déborde. Tire le coin en bas à droite de chaque boîte. Cette page ne contient pas une ligne de JS.

1 · le texte qui grandit vraiment — __w

Je grandis avec ma boîte, continûment — pas par paliers.

__w
__ratio 
<z-size class="tirable">            <!-- `resize: both` est natif : le coin à tirer -->
  <p class="fluide">…</p>
</z-size>

.fluide { font-size: calc(13px + var(--z-size__w) * 0.02px); }   /* continu, pas par paliers */

Une requête de conteneur répond oui/non à un palier fixé d'avance ; ici on a le nombre, donc une interpolation. Les deux vont ensemble : le palier pour changer de mise en page, le nombre pour tout ce qui glisse.

2 · l'ombre qui ne ment pas — __over-y

Agrandis la boîte jusqu'à ce que tout tienne : l'ombre du bas et la flèche disparaissent exactement à ce moment-là.

Rétrécis-la : elles reviennent. C'est le geste que tout le monde rate, faute d'une réponse en CSS — alors l'ombre reste affichée en permanence, et elle ment la moitié du temps.

Le débordement est surveillé sur la boîte et sur ses enfants : une image qui finit de charger change la suite sans changer la boîte.

↓ il y a une suite
__over 
/* l'ombre et la flèche n'existent QUE s'il y a une suite */
.suite       { opacity: var(--z-size__over-y); transition: opacity .2s ease; }
.flecheSuite { opacity: var(--z-size__over-y); transition: opacity .2s ease; }

--z-size__over-y vaut 1 tant qu'il reste quelque chose à voir. Un pixel de tolérance évite qu'elle clignote sur un arrondi de rendu.

3 · la forme, pas la taille — __ratio

Rends la boîte plus haute que large : la vignette prend toute la largeur. Recouche-la : elle reprend sa place à gauche.

 
/* un interrupteur 0/1 : 1 quand la boîte est plus haute que large */
.forme { --debout: clamp(0, (1 - var(--z-size__ratio)) * 1000, 1); }

/* couchée : la vignette prend 40 % · debout : elle prend tout */
.vignette { flex-basis: calc(40% + var(--debout) * 60%); }

La bascule ne dépend d'aucune dimension, mais de leur rapport — ce qu'une requête de conteneur ne sait pas poser, puisqu'elle ne regarde qu'un côté à la fois.
