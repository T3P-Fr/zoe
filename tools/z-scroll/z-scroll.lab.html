z-scroll — le défilement, donné au CSS

Une balise posée n'importe où, et toute la page sait où elle en est. Cette page ne contient pas une ligne de JS — barre, bandeau, flèche et parallaxe lisent tous le même nombre.

1 · la page — <z-scroll page>

le décor glisse quatre fois moins vite que la page
<z-scroll page></z-scroll>          <!-- posée n'importe où : elle pose sur :root -->

.progression { width: calc(var(--z-scroll__ry) * 100%); }        /* la part, 0 → 1 */

.remonter    { opacity: calc(1 - var(--z-scroll__top)); }        /* rien tant qu'on est en haut */

/* (dir + 1) / 2 vaut 1 en descendant, 0 en remontant · (1 - top) annule tout au sommet */
.bandeau     { translate: 0 calc((1 - var(--z-scroll__top))
                              * (var(--z-scroll__dir) + 1) / 2 * -110%);
               transition: translate 260ms ease; }

.scene i     { translate: 0 calc(var(--z-scroll__y) * -0.25px); }   /* le parallaxe */

La barre en haut lit --z-scroll__ry (la part parcourue, 0→1). La flèche lit __top. Le bandeau combine __dir et __top en une seule déclaration. Le décor multiplie __y par un facteur plus petit — c'est tout le parallaxe.

2 · une boîte — <z-scroll>, sans attribut

Cette boîte pose ses propres nombres, sur elle-même.

Ils ne sortent pas d'ici, et ceux de la page ne rentrent pas : à l'intérieur, elle les couvre. Deux boîtes voisines ne se marchent donc jamais dessus.

Les deux ombres, en haut et en bas, disent qu'il reste quelque chose à voir.

Elles s'effacent exactement quand il n'y a plus rien — __top et __end.

Défilez jusqu'ici : l'ombre du bas vient de disparaître, et la jauge est pleine.

 
<z-scroll class="boite">            <!-- sans attribut : l'élément EST la boîte qui défile -->
  <i class="ombre haut"></i>        <!-- DANS la boîte : une variable ne remonte pas -->
  …
  <i class="ombre bas"></i>
</z-scroll>

.ombre.haut { position: sticky; top: 0;
              opacity: calc(1 - var(--z-scroll__top)); }
.ombre.bas  { position: sticky; bottom: 0;
              opacity: calc(1 - var(--z-scroll__end)); }

Les ombres et la jauge sont dans la boîte : elles lisent donc SA part parcourue. Posées dehors, elles liraient celle de la page — chaque nombre reste chez lui, et c'est l'héritage CSS qui trace la frontière, pas une règle de plus à retenir.
