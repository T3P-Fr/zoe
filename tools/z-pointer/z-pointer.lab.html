z-pointer — la souris, donnée au CSS

L'outil ne peint rien : il pose des nombres sur lui-même. Une variable CSS hérite, donc tout ce qu'il enveloppe les lit gratuitement. Cette page ne contient pas une ligne de JS — tout est en CSS.

1 · le geste central — <z-pointer>

ce div est trois niveaux plus bas personne ne lui a rien passé — il hérite, et il tourne 
<z-pointer>                          <!-- sans attribut : le repère local -->
  <div class="halo"></div>
  <div><div><div class="carte">…</div></div></div>
</z-pointer>

.halo {
  translate: calc(var(--z-pointer--local__x) * 1px)
             calc(var(--z-pointer--local__y) * 1px);
  opacity: var(--z-pointer--local__in);          /* 1 dedans, 0 dehors */
}

.carte {                                         /* trois niveaux plus bas : il hérite */
  transform: perspective(700px)
    rotateY(calc((var(--z-pointer--local__rx) - .5) * 26deg))
    rotateX(calc((var(--z-pointer--local__ry) - .5) * -26deg));
}

Le halo lit --z-pointer--local__x/y (des pixels). La carte, elle, lit les ratios __rx/__ry (0→1) et les multiplie par des degrés — un nombre devient ce qu'on veut. Sors de la boîte : __in passe à 0.

2 · il traîne — un nombre typé s'anime

 
/* les trois points lisent la MÊME source */
.point {
  translate: calc(var(--z-pointer--local__x) * 1px)
             calc(var(--z-pointer--local__y) * 1px);
}

/* …et la transition porte sur LA VARIABLE, pas sur translate */
.point.retard1 { transition: --z-pointer--local__x 180ms ease-out,
                             --z-pointer--local__y 180ms ease-out; }
.point.retard2 { transition: --z-pointer--local__x 420ms ease-out,
                             --z-pointer--local__y 420ms ease-out; }

Trois points, la même source, trois retards : 0, 180ms, 420ms. La transition ne porte pas sur translate mais sur la variable — transition: --z-pointer--local__x 420ms. C'est ce que @property rend possible, et ça ne coûte aucune image de JS.

3 · le repère global — <z-pointer global>

 
<z-pointer global>                   <!-- le repère de la FENÊTRE -->
  <div class="mire"><i></i><i></i></div>
  <div class="jauge"><i></i></div>
</z-pointer>

.mire i  { position: fixed;
           translate: calc(var(--z-pointer--global__x) * 1px)
                      calc(var(--z-pointer--global__y) * 1px); }

.jauge i { width: calc(var(--z-pointer--global__rx) * 100%); }   /* le ratio → une part */

La mire suit la souris sur toute la page, y compris ici, loin de sa boîte — global écoute le document. La jauge lit le même mouvement en __rx et le multiplie par 100%. Demande local global et tu as les deux repères à la fois.
