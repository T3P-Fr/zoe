z-channel — le canal, en direct

Le même nom de canal sur deux éléments les relie. Ce qui change ici bouge là-bas — et c'est le CSS qui décide quoi. Zéro classe, zéro écouteur.

1 · curseur → barre

<input type="range" channel="tempo">
<div class="barre" channel="tempo"></div>

.barre { width: calc(var(--z-channel-tempo) * 1%); }

Un <input> émet, une <div> vide lit --z-channel-tempo. Rien entre les deux.

2 · deux canaux → un point 2D

<input type="range" channel="px">
<input type="range" channel="py">
<div class="point" channel="px py"></div>   <!-- deux noms, deux tokens -->

.point { left: calc(var(--z-channel-px) * 1%);
         top:  calc(var(--z-channel-py) * 1%); }

Le point porte channel="px py" : deux tokens, une position. Multi-canal gratuit, sans plafond.

3 · le monde parle — tune()

Une valeur peut venir d'ailleurs qu'un doigt. Le canal est bidirectionnel : les curseurs de l'essai 1 suivent.

import { tune } from "./z-channel.js";

/* le seul JS de cette page : le monde pousse une valeur DANS le canal */
bouton.addEventListener("click", () => tune("tempo", 100));

Chaque bouton appelle tune("tempo", n) — la barre ET le curseur de l'essai 1 se replacent.
