z-drag — déplacer à la main, sans écrire le déplacement

L'outil ne déplace rien : il pose la position, et le CSS décide ce qu'elle bouge. Tire à la souris, au doigt — ou au clavier : tabule jusqu'à un objet et utilise les flèches (10 px avec Maj). Cette page ne contient pas une ligne de JS.

1 · l'objet qu'on tire — __x · __y · __held

tire-moi 
<z-drag class="palet" bounds tabindex="0">tire-moi</z-drag>

.palet {
  translate: calc(var(--z-drag__x) * 1px) calc(var(--z-drag__y) * 1px);

  /* __held : le nombre qu'on oublie, et c'est lui qui donne le POIDS */
  scale: calc(1 + var(--z-drag__held) * .06);
  box-shadow: 0 calc(3px + var(--z-drag__held) * 14px)
                calc(8px + var(--z-drag__held) * 22px) rgb(0 0 0 / .28);

  /* jamais de transition sur translate : l'objet doit coller au doigt */
  transition: scale .18s ease, box-shadow .18s ease;
}

bounds le garde dans son cadre. __held le soulève pendant qu'on le tient — c'est le nombre qu'on oublie, et c'est lui qui donne le poids. La transition ne porte jamais sur translate : l'objet doit coller au doigt, pas traîner derrière.

2 · un curseur, sans composant curseur — __rx

<div class="piste">
  <z-drag class="poignee" bounds axis="x" tabindex="0"></z-drag>
</div>

.piste   { position: relative; overflow: hidden; }
.poignee { position: relative;
           translate: calc(var(--z-drag__x) * 1px) 0;
           background: hsl(calc(var(--z-drag__rx) * 120) 65% 50%); }   /* rouge → vert */

/* la barre remplie est peinte par la POIGNÉE et coupée par la piste :
   une variable ne descend que dans les enfants, jamais vers le parent */
.poignee::before {
  content: ""; position: absolute; top: 50%; right: 50%;
  width: 100vw; height: 10px;
  background: var(--z-accent);
}

bounds allume --z-drag__rx : la part parcourue, 0→1 — ici elle devient la couleur de la poignée, du rouge au vert. Aucun composant « slider » n'a été écrit, et axis="x" rend le défilement vertical à la page, ce qui compte au doigt.
La barre remplie est peinte par la poignée, et coupée par la piste : une variable ne descend que dans les enfants, donc le parent ne peut pas la lire. On inverse le sens plutôt que d'inventer une exception.

3 · le geste n'est pas un déplacement

À gauche : le même geste devient une rotation. À droite : il devient une couleur. Ni l'un ni l'autre ne se déplace. Aucune option ne pouvait couvrir ça — un nombre, si. 

/* le MÊME geste, le MÊME nombre — seule la propriété change */
.molette { rotate: calc(var(--z-drag__x) * 2deg); }
.teinte  { background: hsl(calc(var(--z-drag__x) * 2) 70% 55%); }
