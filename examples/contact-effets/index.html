Mon effet de clic — éclat

Cliquez et maintenez sur un bouton : l'énergie se concentre et tremble. Relâchez : ça explose. Changez de peau en haut à droite — la couleur suit.

MAINTENEZ, PUIS RELÂCHEZ appuyez · gardez le doigt · relâchez
Un bouton Un autre ton

Ce qui produit cet effet

Deux états, deux calques. Rien d'autre — pas une ligne de JS.

<z-contact fx="eclat"></z-contact>      <!-- la page dit « le moteur tourne ici » -->
<link rel="stylesheet" href="./mon-effet.css">

/* PENDANT L'APPUI — l'énergie monte et tremble */
z-contact:state(press) {
  background: radial-gradient(circle, color-mix(in oklab, var(--c) 60%, transparent), transparent 72%);
  animation: eclat-souffle .45s ease-in-out infinite alternate;
}
z-contact:state(press) z-foreground {          /* z-foreground = l'anneau */
  border: 2px solid var(--c);
  animation: eclat-resserre .45s ease-out forwards,
             eclat-tremble  .09s steps(2) infinite;
}

/* AU RELÂCHEMENT — ça explose */
z-contact:state(release) z-foreground {        /* l'onde de choc jaillit */
  border: 3px solid var(--c);
  animation: eclat-onde .5s cubic-bezier(.15, .8, .3, 1) forwards;
}
z-contact:state(release) z-marker {            /* z-marker = le cœur : il éclate */
  background: var(--c);
  animation: eclat-burst .4s ease-out forwards;
}

Le fichier complet est examples/contact-effets/mon-effet.css — ce dossier. var(--c) est la couleur, posée par le moteur : elle suit la peau. Éditez, rechargez.
