Palette — attrape, dépose n'importe où

Attrape une pastille ou la barre de dégradé, lâche-la sur n'importe quel élément de l'aperçu. Clique les ronds pour changer les couleurs du dégradé, tire la réglette pour l'angle.

Matière — jette une couleur sur le héros

Lance une pastille sur le héros → éclaboussure + dégradé. Ou empoigne ses coins (radius par coin) et ses bords (padding par côté). Shift = le haut · Alt = le bas · Shift+Alt = les 4. Le survol montre ce que tu touches. Le héros sculpté reforme toute l'app.

L'établi

On ne règle pas.
On sculpte.

Braque la lumière, tire les rayons, jette une couleur, empoigne les coins. Tout ce que tu vois — couleurs, dégradés, bordures, ombres, l'app entière — descend de tes gestes. Le héros que tu sculptes reforme chaque carte, chaque bouton.
